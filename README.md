## 職務経歴

### 2022年10月-現在: ギリア株式会社

AIを組み込んだアプリケーションおよび社内向けのソフトウェアの開発に従事。

* **カーレースの画像解析/実況生成コンテナの開発 (2025年02月-2025年07月)**  
  * **役割**: メンバー (開発チーム人数: 3人)  
  * **使用技術**: Python, Java, Tsurugi, Docker  
  * **プロジェクト概要**: リアルタイムに画像解析を行い、カーレースのライブ映像に付加価値をつける  
  * **貢献**: 動画フレームの画像化処理、データの読み書きを行うポーリング処理、およびアプリケーション実行用コンテナの開発を担当。AIチームと協働し、実況生成にかかる時間を60秒から13秒に短縮し、ボトルネックの解消に貢献した。また、実況生成の課題となっていたAIの読み込み時間をJavaからPythonに使用技術を変更することで、数十ミリ秒から数ミリ秒に抑えた。これにより、実用に耐えうるシステムの開発に貢献した。  
* **機械学習向け社内計算機環境の運用効率化及びコスト最適化 (2023年12月-2025年08月)**  
  * **役割**: メンバー (開発チーム人数: 4人)  
  * **使用技術**: Terraform, Google Cloud, Looker Studio,BigQuery, Azure  
  * **プロジェクト概要**: オンプレミスおよびクラウド環境の計算機環境の管理を行い、AI開発者の業務効率を最大化する。また、クラウドインフラ環境の管理やサービスの利用コストを可視化し、余剰コストを削減する。  
  * **貢献**: オンプレミス計算機環境の運用およびTerraformを用いたGoogle Cloudプロジェクトの管理を担当。また、Looker StudioとBigQueryを用いて、Google CloudやAzureの利用コストの可視化を担当した。これにより、AI開発者のオンプレミス管理工数を80％削減し、不要なGoogleCloudプロジェクトを20個以上削除することで、業務効率の向上と余剰コストの削減に貢献した。  
* **社内横断検索システムの開発 (2024年02月-2025年01月)**  
  * **役割**: 開発リーダー (開発チーム人数: 2人)  
  * **使用技術**: Terraform, Compute Engine, Cloud Run, BigQuery, Vertex AI Search  
  * **リーダーとしての役割**: 提案資料の作成、技術選定、アーキテクチャ設計、タスク管理  
  * **プロジェクト概要**: 社内に分散する資料を一括管理し、資料探しにかかるコストを削減する。  
  * **貢献**: 社内環境改善業務としてプロダクトの提案・開発を担当。社内の文書を元に回答を生成するAI（RAG+LLM）やVertex AI Searchを利用してモックアプリを作成した。また、Vertex AI SearchやCloud Run+Compute Engineの知見をドキュメント化し、社内共有することで社内の技術力向上に貢献した。  
* **機械学習用データの開発で使用するインフラ環境の構築(2023年11月-2024年06月)**  
  * **役割**: 開発リーダー (開発チーム人数: 3人)  
  * **使用技術**: AWS CDK, TypeScript, Python, Google Apps Script, Google Cloud  
  * **リーダーとしての役割**: 提案資料の作成、アーキテクチャ設計、タスク管理、コードレビュー  
  * **プロジェクト概要**: 機械学習用データ作成業務で使用する環境のコスト計算と構築を自動化し、機械学習用データ作成業務外の工数を低減する。また、開発進捗可視化のため、進捗状況を集計できる環境を用意する。  
  * **貢献**: 社内で複雑な画像へのアノテーションを実施する際に、個人情報に配慮する必要があるデータを扱うことがある。これらの個人情報を含むデータは個人の作業用PCにダウンロードさせたくない。そのため、ゼロコピーでアノテーション業務を行える環境をAWS上に構築した。また、Google Apps ScriptとGitHub Actionsを用いてこの環境構築の自動化を実施した。また、アノテーションの進捗状況を可視化するツールを開発し、これによりアノテーション業務の管理の工数削減に貢献した。
